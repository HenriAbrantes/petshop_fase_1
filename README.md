# Patas & Companhia Pet Shop

Projeto da Fase 1 da disciplina Fundamentos de Sistemas Web (PUCRS).

## Objetivo

Desenvolver um site para um petshop fictício utilizando exclusivamente HTML5, apresentando a empresa, seus produtos e seus serviços.

## Estrutura dos arquivos

```
├── index.html        Página inicial
├── produtos.html     Catálogo de produtos
├── servicos.html     Serviços oferecidos
├── ajuda.html        Informações de ajuda
├── README.md
└── images/           Imagens dos produtos
```

## Funcionalidades

- Cabeçalho, menu de navegação e rodapé em todas as páginas.
- Catálogo com seis produtos em três categorias (acessórios, rações não perecíveis e higiene e limpeza), com imagem, nome, descrição e preço.
- Serviços de banho, tosa e banho e tosa com e sem tele-busca, com descrição e preço.
- Página de ajuda com orientações de navegação.

## Como acessar

Abra o arquivo `index.html` em um navegador ou acesse a versão publicada no GitHub Pages.
